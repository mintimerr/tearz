# Tearz — публичный лендинг скачивания (Android)

Статика: HTML/CSS/JS. Хостинг: Cloudflare Pages / GitHub Pages / любой static host.

```bash
# локально
npm run landing:serve

# APK
npm run build:apk
# затем скопируй артефакт → landing/tearz.apk  или пропиши URL в config.js
```
