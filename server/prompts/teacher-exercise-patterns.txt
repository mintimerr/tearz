Exercise style patterns for Tearz Teacher.

These are NOT a fixed database. They are mechanics inspired by HelloChinese / Duolingo / ProgressMe.
Always invent a NEW task for the learner’s topic and level, in the TARGET language (L2).
Adapt every mechanic to ANY L2 (Chinese, English, Spanish, …) — never hard-code Chinese-only content unless L2 is Chinese.

GLOBAL RULES
- Output exactly ONE task card.
- Do not output a whole worksheet, list, section, or multiple numbered items.
- Do not output headings like "一、", "阅读第一部分", "Задание 1".
- Do not say where to type the answer.
- Keep the final output compact enough for one mobile card.
- L2 strings = target language only. Instructions can be in the UI language.

⸻

HELLOCHINESE-STYLE MECHANICS (adapt to L2)

Pattern HC-1: choose translation
Show one L2 word/phrase; 4 options in the UI language (or reverse: UI word → L2 options).
Example (L2 English): What does “library” mean?
A. библиотека  B. аптека  C. вокзал  D. музей

Pattern HC-2: choose reply (mini dialogue)
One short line from speaker A; pick B’s natural reply.
A: 你吃饭了吗？
A. 吃了。  B. 我是学生。  C. 明天星期一。  D. 这本书很贵。

Pattern HC-3: odd one out
Four L2 words on the same “screen”; one does not belong thematically.
Which word does not belong?  apple / banana / bus / orange

Pattern HC-4: what do you say
Describe a situation in the UI language; pick the natural L2 phrase.
You meet a friend in the morning. What do you say?
A. Good morning!  B. Good night!  C. See you yesterday.  D. How much is it?

Pattern HC-5: spot the error
Three short L2 sentences; pick the incorrect one (or pick the wrong word).
Which sentence is wrong?
A. She goes to school.  B. She go to school.  C. She went to school.

Pattern HC-6: pick similar forms
Near-miss options (tones / lookalikes / conjugations / spelling).
Choose the correct form: She ___ home every day.
A. go  B. goes  C. going

Pattern HC-7: complete dialogue
Two-line dialogue with one blank; word bank of 4–6 items.
A: Where is the station?
B: It’s ______ the bank.

Pattern HC-8: build from meaning
Give the meaning in the UI language; learner builds the L2 sentence from shuffled words.
Meaning: «Я люблю кофе.»
Tiles: I / coffee / like / very / much → I like coffee very much.

Pattern HC-9: word ↔ picture
Concrete nouns only; match L2 labels to images.

Pattern HC-10: match pairs
L2 ↔ UI-language (or L2 ↔ pinyin if Chinese beginner).

CLASSIC PATTERNS (still valid)

Pattern A: fill-in-the-blank with a small word bank
（机会 待遇 后果 办法）
如果不认真对待这个问题，可能会产生严重的______。

Pattern B: verb / form choice in one sentence
（申请 执行 管理 改进）
我们需要不断______工作方法。

Pattern C: reading-style multiple choice
他大学毕业以后，在一家外贸公司工作……工作______。
A. 机会 B. 效率 C. 责任 D. 后果

Pattern D: contextual multiple choice (one blank)
为了减少员工的工作压力，公司决定采取一些新的______……
A. 措施 B. 理由 C. 系统 D. 标准

Pattern E: typed blank (grammar)
Put the verb in Past Simple: Yesterday I ______ (go) to the office.

Pattern F: transformation
Make this sentence negative: She watched a movie yesterday.

Pattern G: classic MC
Choose the correct Past Simple form: He ______ his homework last night.
A. do B. did C. does D. doing

Pattern H: correction
Исправь фразу: "Я делал решение вчера".

Pattern I: collocation choice
Выбери естественный вариант: "принять решение" / "сделать решение".

Pattern J: sentence order
Shuffled tiles → one correct sentence.

Pattern K: real vs fake word (DET)
Is this a real word in L2? (pseudo-word must look native to that script)

Pattern L: fill partial letters
Many stud__ enjoy read__.

Pattern M: main idea
3–5 sentence passage → pick the main idea.
