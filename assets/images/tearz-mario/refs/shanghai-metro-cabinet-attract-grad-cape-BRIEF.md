Рефы:

- `shanghai-metro-cabinet-attract-grad-cape-strip.png` — 4 кадра loop (crouch → leap → peak → land)

## Сцена (Mario attract на CRT)

Чёрный экран автомата:

1. **«НАЖМИ»** сверху — красный pixel-текст (CTA), без рамки.
2. **Skyline** снизу — силуэты зданий с жёлтыми окнами; **крыши = платформы**.
3. **Tearz** (тот же round cyan mascot, что в Mario-рефах):
   - **выпускная шляпа** (mortarboard) + жёлтая кисточка;
   - **красный плащ** сзади (развевается в прыжке);
   - **жёлтая книга** в руке (как pickup / диплом).
4. Монетки в воздухе (опционально).

## Loop анимации (strip)

| Кадр | Действие |
|------|----------|
| 1 | На крыше слева, читает книгу / crouch |
| 2 | Отрыв, плащ назад |
| 3 | Пик прыжка между зданиями, книга вверх |
| 4 | Приземление на следующую крышу |

Дальше warp влево / следующий пролёт по skyline. Без геймплея — только витрина.

## Тон

Pixel / arcade / Mario title-screen. Не фотореализм. Корпус Shanghai Metro — шкаф; жизнь только в CRT.
