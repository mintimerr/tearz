# Shanghai Metro cabinet — attract screen

Реф: `shanghai-metro-cabinet-attract-ref.jpg`

## Идея (не «вместо НАЖМИ», а вокруг)

На чёрном CRT экране автомата:

1. **По центру** — крупная кнопка/надпись **«НАЖМИ»** (как сейчас, attract CTA).
2. **Вокруг неё** — мини-сцена в духе Mario attract / title screen:
   - маленький **синий Tearz** (спрайт),
   - прыгает по **зданиям / платформам** (силуэты skyline / metro vibe),
   - собирает **книжки** (или похожие pickups: карточки, билеты),
   - loop анимации, без геймплея для игрока — только витрина.

## Тон

Буквально игровой автомат: CRT, пиксель/arcade, не фотореализм поверх фото корпуса.
Корпус Shanghai Metro ticket machine остаётся «шкафом»; жизнь — только в экране.
